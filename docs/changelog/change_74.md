# change_74 — Убран технический GitHub-блок из AI резюме чека

## Что изменено

- Из результата AI резюме чека убран временный блок `github_seen`.
- Со страницы профиля удалён раздел «Тест: что AI видел по GitHub».
- Сообщение при `403` от GitHub стало точнее: это ограничение публичных запросов без авторизации.

## Обоснование

Технический вывод был полезен для проверки, но в пользовательском результате он шумит. Для обычного чека достаточно рекомендаций модели и понятной ошибки, если GitHub временно не отдаёт публичные данные.
