# Change 56

## Что изменилось

- Нижняя навигация использует ASCII-URL `/nav-icon/*.webp` вместо прямых путей с кириллицей.
- Сервер сам находит нужный `.webp` в `icons/` с учётом Unicode-нормализации имени файла.
- Иконки в нижней шторке увеличены.

## Зачем

На macOS кириллические имена файлов могут отличаться по Unicode-нормализации, из-за чего браузер получает битую картинку. ASCII-URL стабильнее, а увеличенный размер делает иконки читаемыми.
