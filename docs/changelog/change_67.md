## Что изменилось

- Добавлена повторная миграция ресурсов `16`, чтобы старые Docker volume с уже занятым номером `14` всё равно создавали таблицы `resource_topics` и `resource_links`.
- В Telegram добавлена команда `/resources`: она показывает кнопки для поиска ссылок, последних ресурсов и тем.
- Кнопка поиска ресурсов переводит бота в режим ожидания запроса; следующий текст ищет только по полезным ссылкам.

## Зачем

На локальной БД номер миграции `14` уже был занят старым экспериментом, поэтому сайт падал на `/resources` с `relation "resource_topics" does not exist`. Новый номер миграции исправляет существующие базы без удаления данных, а Telegram-интерфейс делает поиск ресурсов понятнее, чем скрытая команда `/links`.
