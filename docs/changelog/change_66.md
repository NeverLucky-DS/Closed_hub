# Change 66

## Что изменилось

- Добавлена таблица `profile_analyses` для приватного карьерного анализа профиля: статус, результат JSON, ошибка, timestamps и источники `resume_path`/`github_url`.
- Добавлен сервис `services/profile_analysis.py`: извлекает текст из PDF-резюме через `pypdf`, берёт публичные данные GitHub без OAuth с timeout и отправляет всё в LLM.
- В `/me` добавлен приватный блок с кнопкой запуска/обновления анализа и выводом результата: карьерная выжимка, стек, сильные стороны, проекты, рекомендации, About-блок и вопросы.
- Миграция анализа профиля добавлена отдельным номером после ресурсов.

## Зачем

Анализ резюме может содержать чувствительные выводы и черновые рекомендации, поэтому он хранится отдельно и показывается только владельцу на странице `/me`. Публичный профиль `/people/{id}` анализ не получает и не отображает.
