# change_70: Правки UX ресурсов — заголовки, иконки, мобайл, дубликаты

## Что изменилось

### 1. Не обрезать заголовок ссылки
- `services/resources_service.py`: лимит title увеличен с 80 до 200 символов
- `web/app.py`: убрана обрезка `[:80]` при сохранении → `[:200]`
- `web/templates/resources.html`: поле `maxlength` в форме 80 → 200

### 2. Иконки папок как в «Файлах»
- В шаблоне `resources.html` папки теперь используют `library-folder-card` / `library-folder-icon` с `<img src="/library-folder-icon.webp">` — аналогично `library.html`

### 3. Мобильное отображение
- В `resources.html` форма «Добавить ссылку» перемещена первой в DOM → на мобайле выводится **выше** сетки папок и списка ссылок
- Строка поиска вынесена **над** двухколоночной сеткой (всегда самая верхняя)
- Контейнер сетки получил `overflow-x-hidden` — горизонтальная прокрутка исключена
- URL в карточках: `break-all max-w-full` — длинные URL переносятся
- Убрано лишнее описание Jina API key из формы; оставлено: «Подходит любая ссылка... Автоматическое заполнение занимает ~15 сек.»

### 4. Проверка дубликатов
- `db/repo.py`: добавлена функция `find_resource_link_by_url(pool, url)` — ищет ссылку с совпадающим URL
- `web/app.py`: дублирование проверяется **на шаге 1** (до вызова Jina) и **на шаге confirm** (перед INSERT) → редирект с ошибкой
- `bot/handlers/messages.py`: проверка до запуска `fetch_and_enrich_link` — бот отвечает, что ссылка уже есть
- `bot/handlers/callbacks.py`: проверка в `rlok` перед сохранением — alert + очистка сессии

## Обоснование
Устраняет повторное добавление одинаковых ссылок, улучшает порядок элементов на мобайле и приводит визуальный стиль папок к единому стандарту проекта.
