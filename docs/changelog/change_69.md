# change_69 — AI-черновик при добавлении полезной ссылки

## Что изменилось

Добавлен двухшаговый пайплайн для добавления ресурсных ссылок:

1. **Jina Reader** читает страницу по URL (`https://r.jina.ai/{url}`) и возвращает чистый текст.
2. **Mistral** разбирает текст и возвращает JSON: `title`, `main_topic`, `description_ru`, `key_topics`, `ai_summary`.
3. Пользователю показывается черновик — он может исправить любое поле перед сохранением.
4. Если Jina или Mistral недоступны — fallback на пустой черновик без AI-данных, сохранение всё равно работает.

### Веб (`/resources`)
- Форма «Добавить ссылку» теперь принимает только URL на первом шаге.
- После нажатия «Далее» страница обновляется и показывает заполненный черновик с полями `title`, `тема`, `описание`, `ai_summary`.
- Пользователь редактирует и нажимает «Сохранить» (скрытый `step=confirm` переключает роут на сохранение).

### Telegram-бот (личка)
- Любое сообщение с URL (или intent `resource_link` от Mistral) запускает обогащение.
- Бот присылает карточку черновика с кнопками «✅ Сохранить» / «❌ Отменить».
- При сохранении тема берётся из AI-черновика (или создаётся новая), ссылка сразу попадает в базу.

### Новые файлы и изменения
- `prompts/resource_link_extract.txt` — промпт для Mistral
- `config.py` + `.env.example` — добавлен `JINA_API_KEY` (опционально)
- `services/resources_service.py` — добавлен `fetch_and_enrich_link()`
- `services/llm.py` — добавлен `enrich_resource_link()`
- `services/routing.py` — новый intent `resource_link`, хелпер `extract_url()`
- `prompts/classify.txt` — добавлен intent `resource_link`
- `web/app.py` — двухшаговый `POST /resources`
- `web/templates/resources.html` — режим черновика
- `bot/handlers/messages.py` — обработка URL и state `resource_link_confirm`
- `bot/handlers/callbacks.py` — кнопки `rlok` / `rlcan`

## Зачем

Раньше при добавлении ссылки пользователь вводил всё вручную, а `ai_summary` всегда оставался пустым. Теперь AI экономит время: заголовок, тема и описание уже заполнены, достаточно проверить и нажать «Сохранить».

## Что можно заменить позже

- Хранить черновик в отдельной таблице `resource_link_drafts` вместо session payload (для поддержки редактирования полей по одному в боте).
- Добавить web-хук или пушить уведомление при успешном сохранении через бот.
