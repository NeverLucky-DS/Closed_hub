# Change 57

## Что изменилось

- Название приложения в шапке, title и manifest изменено на `ML Hub`.
- Значок рядом с названием в верхней шапке и desktop-sidebar убран.
- Нижняя мобильная навигация получила фиксированную высоту без JS-пересчёта.
- У активной вкладки нижнего бара убраны сдвиг и масштабирование иконки.
- Мобильный layout теперь занимает минимум всю высоту экрана, чтобы нижний бар не всплывал на коротких страницах.

## Зачем

Нижняя навигация должна оставаться на месте при смене вкладок и на коротких разделах, а название приложения должно соответствовать текущему бренду.
