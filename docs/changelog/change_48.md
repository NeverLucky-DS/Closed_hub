# Change 48

## Что изменилось

- Добавлен локальный Cursor MCP-конфиг для Lazyweb в `.cursor/mcp.json`.
- Установлен локальный slash skill Lazyweb в `.cursor/skills/lazyweb/SKILL.md`.

## Зачем

Это подключает Lazyweb как Streamable HTTP MCP-сервер для поиска UI-референсов и отдельно включает `/lazyweb` skill в Cursor. MCP-инструменты и slash skill настраиваются разными файлами, поэтому нужны оба шага.
