# change_68 — Группировка мобильной навигации + иконка ресурсов

## Что изменилось

### Иконка ресурсов (`ресурсы.webp`)
- В `web/app.py` добавлен маппинг `"resources": "ресурсы"` в `_NAV_ICON_NAMES`.
- В боковом меню (`base.html`) раздел "Ресурсы" теперь использует `<img src="/nav-icon/resources.webp">` вместо inline SVG.

### Мобильная нижняя панель — сокращена до 5 пунктов
Было 8 пунктов (с горизонтальным скроллом), стало 5:
- **Файлы** → `/library`, активен для `library` и `resources`
- **Новости** → `/feed`, активен для `feed` и `today`
- **Хакатоны** → `/hackathons`
- **Компании** → `/companies`
- **Профиль** → `/me`, активен для `me` и `people`

В `base.css` убран `overflow-x: auto`, `.mobile-tab` переведён на `flex: 1` — пункты равномерно занимают всю ширину без скролла.

### Контекстные переключатели в мобильной шапке
Вкладки расположены **в той же строке, что "ML Hub"**, левее него, точно в том же стиле что нижние вкладки: иконка webp + подпись. Видны только для разделов с дочерними страницами:
- `/library` или `/resources` → вкладки **Файлы | Ссылки**
- `/feed` или `/today` → вкладки **Новости | Выжимка**
- `/me` или `/people` → вкладки **Профиль | Люди**

Новые CSS-классы `.mobile-header-tabs` и `.mobile-header-tab` добавлены в `base.css`.

### Исправлен скролл нижней панели
Убран JS-блок `sessionStorage` сохранения `scrollLeft`, который позволял случайно прокрутить нижнюю панель после перехода. `overflow: hidden` на `.mobile-bottom-nav` теперь работает без побочного эффекта восстановления позиции.

### Боковое меню на десктопе
Подразделы (Ссылки, Выжимка, Люди) визуально сдвинуты вправо (`padding-left:2.5rem`) для обозначения иерархии. Активные состояния родительских пунктов настроены аналогично мобильной версии.

## Обоснование
Пользователь явно запросил упрощение нижней панели: убрать перегруженность, скрыть дочерние разделы за родительскими пунктами, открывать под-навигацию через шапку.
