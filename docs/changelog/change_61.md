# Change 61

## Что изменилось

- Нижняя мобильная навигация снова стала горизонтально скроллящейся.
- Позиция скролла нижней панели сохраняется между переходами, без автоцентрирования активной вкладки.
- Карточки папок в библиотеке стали минимальными: одна рамка, большая иконка `папка.jpeg`, маленькая подпись снизу.
- Добавлен стабильный route `/library-folder-icon.jpeg`, чтобы картинка с кириллическим именем корректно находилась на macOS и в Docker.

## Зачем

Сетка из всех вкладок помещалась на экран, но выглядела тесно. Горизонтальный скролл возвращает нормальный размер вкладок, а сохранение `scrollLeft` убирает старый баг со сбросом панели влево при переходах.
