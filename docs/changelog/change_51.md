# Change 51

## Что изменилось

- Убран автоскролл нижней мобильной навигации к активной вкладке.
- Увеличен нижний отступ основного контента на телефоне, чтобы карточки не прятались за навигацией.
- Карточки компаний теперь показывают квадратный логотип/инициал вместо большой обложки на весь блок.
- У свотчей тем убрана светлая внутренняя окантовка.

## Зачем

Мобильный интерфейс должен ощущаться спокойнее: без резких сдвигов навигации, без перекрытия контента и с более аккуратными карточками компаний.
