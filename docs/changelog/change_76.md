# change_76 — Обновлено файловое хранилище

## Что изменено

- В библиотеку добавлен переключатель `Общее / Личное`: общее показывает все подтверждённые файлы, личное — файлы текущего пользователя.
- На сайте добавлена drag-and-drop загрузка файла с автоматическим AI-разбором и карточкой подтверждения.
- В карточке подтверждения можно отредактировать описание и выбрать «Своя папка» с новым названием.
- Если AI-разбор файла падает, файл всё равно сохраняется как черновик, а сайт просит описать его вручную.
- Действия выбранного файла собраны в компактную строку иконок над предпросмотром.
- Telegram-загрузка и веб-загрузка теперь используют общий код подготовки файлового черновика.

## Обоснование

Файловое хранилище стало удобнее для просмотра своих материалов без отдельной таблицы приватности. Веб-загрузка повторяет привычный сценарий Telegram: файл сначала распознаётся, затем пользователь подтверждает папку, после чего файл виден и в личном, и в общем режиме. Ручное описание нужно, чтобы загрузка не ломалась из-за временных проблем с AI API.
