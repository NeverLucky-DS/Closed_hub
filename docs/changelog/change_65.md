# Change 65

## Что изменилось

- В личке бота добавлены команды `/search`, `/files тема` и `/links тема`.
- `/files` без аргументов по-прежнему показывает последние файлы, а с аргументами ищет по библиотеке: имени файла, summary, subject_tags и папке.
- `/links` ищет по разделу ресурсов и группирует ссылки по темам.
- Команды зарегистрированы только для private chat, чтобы бот не отвечал на них в группе.
- Результаты ограничены короткой выдачей и добавляют ссылки на веб-библиотеку при наличии `WEB_PUBLIC_BASE_URL`.

## Зачем

Так участники могут использовать группу только для общения, а поиск по файлам и полезным материалам держать в личке бота.
