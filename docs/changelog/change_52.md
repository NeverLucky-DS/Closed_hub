# Change 52

## Что изменилось

- Добавлен явный мобильный spacer под нижнюю fixed-навигацию.
- Лента новостей упрощена: карточка стала легче, без ссылок автора, с полным заголовком и раскрытием длинного текста внутри карточки.
- Фото новости показывается только при реальной обложке и вписывается в область без обрезки пропорций.
- Если реальной обложки нет, карточка остаётся текстовой без визуальной заглушки.
- Выжимка разделена на блоки `Сегодня`, `На неделе`, `Позднее`, `Нет даты`; пустые блоки скрываются.

## Зачем

Мобильная лента должна читаться без лишнего интерфейсного шума, а выжимка должна помогать быстро понять, какие новости срочные, какие актуальны позже и у каких нет даты.
