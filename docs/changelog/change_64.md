# Change 64

## Что изменилось

- Добавлен раздел сайта `/resources` для полезных ссылок: папки тем, поиск, карточки ресурсов и форма добавления ссылки активным участником.
- Добавлены таблицы `resource_topics` и `resource_links` в `db/schema.sql` и миграция `14` в `db/schema_patch.py`.

## Зачем

Это MVP базы ссылок для закрытого карьерного хаба: участники могут быстро складывать полезные материалы по темам без модерации. Сервер пока не скачивает URL, поэтому нет SSRF-риска; поля `title` и `ai_summary` оставлены в схеме для будущего безопасного превью/AI-summary.
