# Change 53

## Что изменилось

- Ссылки `http://` и `https://` в тексте новости стали кликабельными в ленте.
- Текст перед выводом экранируется, а ссылкой становится только найденный URL.

## Зачем

Новости часто приходят с регистрационными формами, вакансиями и подробностями по внешним ссылкам. Теперь их можно открыть прямо с сайта.
