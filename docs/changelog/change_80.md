# change_80 — Добавлен GitHub token для AI-чека резюме

## Что изменено

- Добавлена опциональная переменная `GITHUB_TOKEN` в настройки и `.env.example`.
- AI-чек резюме теперь отправляет `Authorization: Bearer ...` в GitHub REST API, если token задан.
- Ошибка `403` теперь различает режим без авторизации и режим с token, чтобы проще понять причину сбоя.

## Обоснование

AI-чек резюме зависит от публичного GitHub API. Без авторизации GitHub быстро режет запросы по IP, поэтому token делает важную функцию стабильнее без расширения прав доступа к приватным данным.
