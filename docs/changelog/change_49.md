# Change 49

## Что изменилось

- Вынесены повторяющиеся визуальные блоки в простые CSS-примитивы в `web/static/css/base.css`: `panel`, `list-row`, `empty-state`, `alert`, `chip`, `file-field`, `dropzone`, `btn-danger`, `danger-panel`, `section-title`.
- Шаблоны профиля, ленты, людей, хакатонов, компаний, библиотеки и выжимки переведены на эти классы, чтобы меньше дублировать длинные Tailwind-цепочки.
- Mobile readiness: нижняя горизонтальная навигация на телефоне, safe-area отступы, `100dvh`, запрет автозума iOS для полей (`font-size: 16px`), минимальная высота кликабельных контролов, правки плотных мест (лента, библиотека, заявки в хакатонах, экран входа).

## Зачем

Так проще поддерживать внешний вид и мобильное поведение: layout остаётся в Tailwind, а повторяемый визуальный стиль и базовые mobile-правила лежат в одном CSS-файле. Логика роутов, форм и JavaScript почти не трогалась.
