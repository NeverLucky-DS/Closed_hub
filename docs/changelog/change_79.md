# change_79 — Добавлен skill для security-аудита проекта

## Что изменено

- Добавлен project skill `project-security-audit` для проверки БД, авторизации, админских прав, файлового хранения и устойчивости сайта.
- В skill зафиксированы порядок проверки, правила сбора доказательств и формат итогового security-отчёта.

## Обоснование

Перед большим аудитом нужен единый чеклист, чтобы проверять проект одинаково и не смешивать подтверждённые уязвимости с теоретическими рисками.
