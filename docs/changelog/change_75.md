# change_75 — Локальный rebuild Docker без Docker Hub

## Что изменено

- Добавлен `Dockerfile.local` для быстрой пересборки кода поверх уже собранных образов `closed_hub-bot` и `closed_hub-web`.
- Добавлен `docker-compose.local.yml`, который переопределяет build-настройки только для локальной пересборки.
- Добавлен `scripts/dev-up.sh`: если локальные образы уже есть, он пересобирает без обращения к базовым образам `python` и `uv`; если образов нет, запускает обычную полную сборку.

## Обоснование

Обычный `docker compose build` может падать на временном `EOF` от Docker Hub при чтении metadata `python:3.12-slim-bookworm`. Для ежедневной разработки зависимости обычно не меняются, поэтому достаточно переложить свежий код в уже собранный образ и перезапустить сервисы.
