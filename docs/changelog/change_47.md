# change_47 — свободные порты для Docker Compose

## Что сделано

- Публикация Postgres на хост: `${POSTGRES_HOST_PORT:-5433}:5432` (дефолт 5433 — чаще свободен, если на хосте уже слушает 5432).
- Публикация веб-сервиса на хост: `${WEB_HOST_PORT:-8001}:8000` (дефолт 8001, если на хосте уже занят 8000).

## Зачем

На машине часто уже заняты 5432 (локальный PostgreSQL / другой контейнер) и 8000 (другой dev-сервер), из‑за чего `docker compose up` падает с «port is already allocated».

## Как пользоваться

В `.env` рядом с compose при необходимости задать, например:

- `POSTGRES_HOST_PORT=5432` — если хочешь именно 5432 на хосте и порт свободен.
- `WEB_HOST_PORT=8000` — если хочешь именно 8000 на хосте и порт свободен.

Для `uv run` с БД в Docker с хоста в `DATABASE_URL` указать тот же порт Postgres на `localhost`. Сервисы `bot` и `web` в compose по-прежнему ходят в БД на `postgres:5432` внутри сети; внутри контейнера веб слушает `WEB_PORT` (8000).
