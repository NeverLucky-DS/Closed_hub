# Worker 5 — `WEB_UVICORN_WORKERS` в `web/main.py`

## Сделано

- Переменная окружения `WEB_UVICORN_WORKERS` (целое число, по умолчанию `1`) читается в `main()` и передаётся в `uvicorn.run(..., workers=workers)`.
- При `workers > 1` пишется **WARNING** в лог: in-memory лимиты авторизации в `web/app.py` привязаны к процессу и между воркерами не совпадают; рекомендация — один воркер или в будущем общее хранилище (например Redis).

## Проверка API Uvicorn

В установленной версии Uvicorn сигнатура `uvicorn.run` включает параметр `workers: int | None = None`. Первый аргумент `app` допускает тип `str` (import string, например `"web.app:app"`). То есть строковый путь приложения с `workers` > 1 поддерживается штатным API.
