# План: VPS Aeza + закрытие техдолга (высокий и средний приоритет)

## Цель

Подготовить репозиторий к безопасному деплою на VPS Aeza: секреты, документация, health для оркестрации, CI smoke, явная политика uvicorn-воркеров, снятие опасного дефолта админов. Низкий приоритет (Redis RL, разбиение `web/app.py`, JSON-логи) **не входит** в этот план.

## Фазы

| Фаза | Содержание | Воркер |
|------|------------|--------|
| 1 | Compose + `.env.example` + README: пароли БД из env, порты, блок про Aeza | 1 |
| 2 | `config.py`: без захардкоженного чужого admin id | 2 |
| 3 | GitHub Actions: `uv sync --frozen` + импорт приложения | 3 |
| 4 | `GET /health`, `GET /ready` | 4 |
| 5 | `WEB_UVICORN_WORKERS`, предупреждение при workers>1 | 5 |

## Что нужно заполнить / ответить (ты — владелец проекта)

Скопируй блок в свой `.env` или заметки и допиши значения **до** первого прод-деплоя.

### Домен и TLS

1. **Публичный домен** сайта (например `https://hub.example.com`): `WEB_PUBLIC_BASE_URL=`
2. Кто терминирует TLS: **Caddy / Nginx / только Aeza LB**? От этого зависят `WEB_PROXY_HEADERS` и `WEB_FORWARDED_ALLOW_IPS` (нужен реальный IP прокси, смотрищий на контейнер).

### База

3. **Пароль Postgres в проде** — сгенерируй длинную строку; в `.env` для compose: `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, согласованный `DATABASE_URL` на хосте (если бот не в Docker — порт с хоста).

### Админы сайта

4. **Telegram user id** всех, кто может удалять файлы / скрывать новости: `WEB_ADMIN_TELEGRAM_IDS=` (через запятую). Пусто = никто.

### Бэкапы (ручной runbook)

5. Куда складывать бэкапы (путь на VPS или внешнее хранилище): _______________
6. Частота `pg_dump`: _______________

Пример (подставь свои пути):

```bash
docker compose exec -T postgres pg_dump -U closedhub closedhub | gzip -1 > /backup/closedhub-$(date +%F).sql.gz
```

### Aeza-специфика

7. Если у Aeza **фиксированный внутренний IP** reverse proxy — запиши его в `WEB_FORWARDED_ALLOW_IPS` вместо широкого списка.
8. Открытые порты: обычно наружу только **80/443** на прокси; `WEB_HOST_PORT` не обязан быть публичным, если доступ только через прокси на `127.0.0.1:8001`.
